# PLAY 90

تطبيق كرة قدم لنظام Android مبني باستخدام Flutter.

## تشغيل المشروع
1. ثبّت Flutter وAndroid SDK في بيئة التطوير.
2. افتح مجلد المشروع.
3. نفّذ:
   ```bash
   flutter pub get
   flutter run
   ```

## الحالة الحالية
هذه نسخة بداية للواجهة الرئيسية فقط. لا تحتوي بعد على بث مباشر أو روابط قنوات أو لوحة تحكم أو إعلانات.
